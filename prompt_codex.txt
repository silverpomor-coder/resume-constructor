Проект: Конструктор резюме по корпоративному шаблону

Общая идея:
Программа читает загруженный файл и сравнивает его со схемой шаблона (шаблон папке с именем CV_эталон), распознает данные, соответствующие разделам шаблона – фамилия имя отчество телефон персональные данные, такие как место регистрации, место рождения и так далее. 

После обработки в автоматическом режиме выводит на экран форму для проверки и ручной корректировки данных

По команде пользователя сохраняет переработанный файл в специальную папку с именем готовые резюме

Фронтэнд:
На твое усмотрение строгий MVP с аккуратными шрифтами и возможностью перетягиванием мышью изменять размеры сетки
Фон светло-серый, фон контейнеров - белый
2 колонки

1 - окно просмотра текста содержимого файла
2 - вывод финального (распознанного) документа
3. Колонка редактирования с названием блоков и данными, которые предлагается вставить в итоговое резюме. Если по каким-то разделам данные не распознаны, строка ввода пустая.

Колонки эластичные, захватом мышки можно изменить ширину. При изменении ширины растягивается колонка справа от захваченной линии размётки сужается колонка слева. Остальную механику додумать сам с учётом необходимости постоянно видеть на экране основные заголовки
Кнопки
Загрузить – открывается проводник по клику выгружается выбранный файл, автоматически создается его копия в папке Start
Сохранить – файл после обработки сохраняется в папке в формате DOCX

Как работает:
При открытии файла doc, docx, rtf, txt, odt сначала производится его нормализация для последующего сохранения в формате DOCX только после этого он выводится в окно просмотра.
После загрузки файла или открытия из проводника конструктор находит все данные, по смысловому соответствию заголовкам и разносит их соответствующим ячейкам. В правой колонке появляются те же данные в виде отдельных строк с названиями и полем ввода где их можно отредактировать вручную, либо не трогать и оставить как есть. 

Если в соответствующие ячейке данные нет ни при автоматической обработке ни при ручном редактировании, в выходном файле ячейка остается пустой.
Родительские заголовки в эталонном шаблоне имеют светло голубую заливку. В выходном обработанном файле сохранять заливку только родительских заголовков
После загрузки файла или открытие ранее сохранённого из левой колонки появляется возможность редактировать данные в каждой ячейке.

Фотографию из исходника переносить в финальный файл в соответствующее место, логотипы, колонтитулы исходника не переносить. В шаблоне финального резюме сохранить колонтитул с логотипом и реквизитами столичного сервисного агентства

Требования к формату выходного файла: сохранить структуру разметку таблицы видимость границ таблиц логотип взаимная расположение отдельных таблиц блоков ячеек как в талоном файле. При автоматическом распознавании ничего не придумывать переносить данные из исходника как есть.
